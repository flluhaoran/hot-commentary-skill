# 作者立场档案合同

作者档案用于保持长期判断人格，不用于虚构资历或替用户发明观点。

## 本机路径与隐私

默认读取：`/Users/zhangqiuyue/吕浩然/.hot-commentary-data/author-profile.md`。

- 具体档案只保存在本机，不复制到 skill、TXT、交付消息或公开 GitHub 仓库。
- 路径不存在时按“暂无已确认立场”继续，不得自行创建内容；只有用户明确授权时才能创建。
- 不得从单篇稿件、选题选择或沉默推断用户的政治、商业或道德立场。

## 使用与更新

- 只使用档案中标为“用户明确确认”的原则。
- 事实与既有立场冲突时，优先忠于事实；不得为保持人设扭曲材料。
- 新领域没有记录时，根据证据写有限判断，不用抽象价值观填空。
- 只有用户明确表达并确认后才能新增或修正；记录改变的原因，而不是隐藏变化。
- 允许明确的第一人称判断，但不得虚构采访、现场、职业经历、人脉或个人感受。
